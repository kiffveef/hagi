# Code Style

- Follow existing code conventions
- Versions: no spaces — `Rust1.75`, `Python3.12`
- Parentheses: half-width `()` only
- Japanese text: no spaces between half-width alphanumerics and Japanese — `Rust製のCLI`, not `Rust 製の CLI`
- Comments: own line only, explain "why" not "what", one line preferred
